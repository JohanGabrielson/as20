# Overview

This contains two tools to generate and crack MD5 hashes:

## Code description:

## md5-hashcat.sh 
Bash script that runs Hashcat to crack MD5 hashes using a mask attack.  The script checks 
that hashcat is installed before executing. 

## generate_md5.py
Python script that generates random passwords and print their  MD5 hashes. The 
password length has a sufficient length to resist attack of rainbow tables lookups. 

## my-hashes.txt
Textfile that contains 10 hashes generated by the Python script. 


## Usage:
Before running the Bash script:

``` 
chmod +x md5-hashcat.sh
```

To run the Bash script: 

``` 
./md5-hashcat.sh
```

To run the Python script: 

``` 
python3 generate-md5.py

```
