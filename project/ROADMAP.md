# 🗺️ Project roadmap
<p> Long term development plan for Password Security Checker </p>

## 🔍 Overview 
This is a roadmap of the future development of Password Security Checker. It will gradually move from a Bash-based script into a cross platform password auditing tool with deeper analysis and improved performance. </p>

## 🚀 Short term goals
<ol>
  <li>Fuzzy wordlist</li>
  <li>Make it possible to choose wordlists other than rockyou.txt</li>
  <li>Expand man page and help section and overall documentation</li>
  <li>More detailed logging</li>
</ol> 

## 🧭 Mid term goals
<o1>
  <li>Detect keyboard walk patterns (such as qwerty)</li>
  <li>Detect common password templates (such as Password!23) </li>
  <li>Normalize 1337 substitutions (p4ssPhr4s3 = passphrase)</li>
  <li>Add offline mode</li>
</o1>

## 🧩  Long term goals
<o1>
  <li>Python port</li>
  <li>Windows compatibility</li>
  <li>GUI</li>
</o1>


## 📅 Verison plan
<o1>
  <li>v1.0 - Initial Bash release</li>
  <li>v1.1 - Fuzzy matching + pattern detection</li>
  <li>v1.2 - Plugin architecture + offline mode</li>
  <li>v2.0 - Python port</li> 
  <li>v2.1 - Windows support</li>
  <li>v3.0 - GUI</li>  
</o1>
